# 动画脚本与 PowerPoint 电脑操作

## 根据画面编写脚本

默认保留静态画面。先明确动画要解释的实际关系，并判断静态并排图、箭头或标注是否已经足够清楚；只有动画能明显增进理解时才制作。单纯让文字、流程框、图表分批出现，或仅为配合讲者控制阅读顺序，不足以成为加动画的理由。不设每页动画或点击次数的目标，整份无需动画也可以。

适合动画的情形包括：展示随时间发生的变化、表达物体或信号的运动、关联整图与局部位置、演示操作引起的状态变化，以及用前后连续状态解释因果机制。流程图、成对实验和复杂论文图都要单独判断；静态呈现已清楚时不添加动画。

例如整图定位后揭示对应局部，可以帮助观众建立空间对应；模拟凸起缺陷被生成方法抹除时，其阴影也随之消失，可以解释为何差分把阴影算成异常。实际采用哪种效果取决于画面，不把这些例子当作每份汇报必须包含的动作。保留标题、坐标、图例、关键条件与比较所需的参照，避免动画改变证据含义。

只为选中的画面编写具体脚本，其余页标为静态即可。

每页脚本记录以下内容，足以据此操作 PowerPoint。

| 字段 | 要记录的内容 |
| --- | --- |
| 页面 | 页标题、当前页码和对象定位线索 |
| 初始画面 | 放映刚进入本页时可见的对象 |
| 讲解 | 这一刻要说的内容，以及引发下一次点击的语句 |
| 操作对象 | 图片、文本、箭头、图表系列或组合对象的明确名称 |
| 动画的解释收益 | 要表达的实际关系，以及动画比静态呈现清楚在哪里 |
| 动画 | 出现、强调、退出或运动的效果及其表达目的 |
| 触发与时间 | 单击、与上一动画同时、上一动画之后，以及时长与延迟 |
| 结束画面 | 这一段讲完后应同时可见的证据 |

先按脚本检查听众在每个步骤能否理解画面。对象不便单独揭示时，在制稿阶段拆出所需 panel，或准备正确的组合与遮罩。图像裁切和遮罩应保留支撑结论的数据、标签与空间对应关系。图表动画应保留数值和坐标含义。

把脚本放入讲者备注，交付时附一份与最终页序一致的可读动画脚本。局部修改同步更新受影响的页面和对象。

## 获取实际操作权限

在开始 PowerPoint 动画制作前，使用当前可用的电脑操作工具选择 PowerPoint，并读取界面状态，确认已打开的演示文件与用户指定目标一致。按该工具返回的文档调用接口，依据当前屏幕定位控件。

通过工具提供的授权入口检查或申请控制权限。系统实际提示需要辅助功能、屏幕访问或自动化授权时，向用户说明具体提示、需要完成的操作和授权位置，沿用本会话已授予且仍有效的权限。权限请求只覆盖完成此次演示制作所需的操作。

用户正在编辑演示时，先确认当前文件与保存状态，保护未保存的修改。若需要用户在系统界面完成授权，先完成可独立进行的画面整理和脚本，待权限可用后接续动画制作。

## 用电脑落实原生动画

1. 打开目标演示文件并核对页标题与关键画面。在添加动画前读取现有动画，按本次制作或修改范围调整。
2. 根据脚本选择和命名对象，建立图片、标注、箭头所需的组合。使用 PowerPoint 的动画菜单与动画窗格设置效果、顺序、触发方式、时长和延迟。
3. 同一对象包含多个效果时，检查新增效果是否正确保留已有步骤。相关对象同时揭示时设置相应组合或同步触发。
4. 完成一组相关页面后保存，并从这些页面开始放映，逐次点击检查。根据实际画面修正对象顺序、遮挡和时间。

通过电脑操作将脚本落实到交付的 PowerPoint 文件。若某项计划效果受当前应用功能限制，选择能表达同一关系的原生效果，并同步更新脚本。工具、文件或权限问题阻塞时，明确记录受影响页面和具体未完成步骤，便于接续。

## 放映与保存验收

- 从每个有动画的页面初始状态开始，逐步核对点击顺序、同时出现的对象和口头讲解。
- 检查初始画面及结束画面，确认必要证据可读，移动、进入和退出后的对象没有遮挡数据或引起比较位置漂移。
- 检查跨页衔接和回退后的显示状态，使实际放映能按脚本继续。
- 保存后重新打开演示，抽查动画窗格与放映步骤，确认动画保存在最终文件中。保留关键步骤的界面或播放检查记录。

交付说明与实际状态对应，清楚报告已在 PowerPoint 中完成并检查的动画，以及仍受阻的步骤。
